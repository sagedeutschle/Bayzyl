# Bayzyl 0.2.0-alpha.2

A builder reliability pre-release for Paper 1.21.11 and Java 21.

## What changed

- Crash recovery writes snapshots atomically, keeps a backup, and preserves legacy or rejected payloads before migration. Durable clipboards survive clean restarts and abrupt stops. `/resume` retries an interrupted **copy** with its saved selection.
- Redstone Audit adds `/redstoneaudit` and `/bzl audit`: read-only circuit hints, paginated findings, and private particle markers that expire after about 30 seconds. It checks up to 131,072 selected blocks with a two-block context border and refuses unloaded regions.
- Edit and brush work estimates reject oversized operations before allocation. Formula parsing has size/work limits, reports evaluation errors, and gives exponentiation precedence over unary minus. Native selections are clipped to world height; volume arithmetic cannot wrap around safety checks.
- Invalid masks no longer widen to every block. Malformed material syntax, nonfinite distribution weights, unknown coordinate modes, unsafe teleport destinations, and invalid saved brush names are rejected.
- Cancelled chunked cut/paste operations record the changes already applied for undo. Quit and shutdown flush partial edits before saving history. New Bayzyl commands and tool edits wait while that player's edit or undo/redo is running.
- Clipboard fixes cover negative quarter-turns, stair corners, wire connections, vertical halves, door hinges, chest sides, free-entity positions/yaw, and even-sized painting anchors.
- Legacy cloud/lightning brush codes load correctly; detail tracking is bounded. Shared kit overwrite works without accepting alias collisions. Autocomplete omits legacy materials and command registration syncs once per batch.
- Permission/descriptor checks, recovery failure tests, build metadata, checksums, reproducible builds, and plugin CI accompany the release.

## Install or upgrade

1. Back up worlds and `plugins/Bayzyl/` while the server is stopped.
2. Download `bayzyl-0.2.0-alpha.2.jar` and `bayzyl-0.2.0-alpha.2.jar.sha256` from this release. Check them with `sha256sum -c bayzyl-0.2.0-alpha.2.jar.sha256` (macOS: `shasum -a 256 -c bayzyl-0.2.0-alpha.2.jar.sha256`).
3. Replace the old plugin JAR; do not leave two Bayzyl versions in `plugins/`.
4. Start Paper with Java 21, check the startup version/revision, and try a small edit/undo in a test area.

The attached receipt identifies the source revision and exact JAR. The release's validation record distinguishes unit tests, disposable server checks, and visual acceptance. Existing server installations are not updated by downloading or publishing this release.

## Recovery behavior

Unversioned 0.1 recovery files are migrated after their original bytes are preserved. Invalid records are reported rather than silently accepted. If both primary and backup are unreadable, recovery is disabled for that run and the files remain available for inspection; ordinary plugin startup can continue.

Recoverable clipboards are limited to 250,000 blocks. `/resume` currently supports interrupted copy only: it repeats that copy, and waits if its world is unavailable. It does not resume arbitrary commands, rebuild an interrupted paste/cut after process death, or promise a complete snapshot of a Minecraft world. Cleanly cancelled edits and abrupt process termination are different cases.

## Known limits

- This is an alpha. Keep world backups. Undo records block data and selected entity changes; it does **not** guarantee restoration of container inventories, sign text, or every block-entity payload.
- Item-frame/painting movement issue [#1](https://github.com/sagedeutschle/Bayzyl/issues/1) remains open. The transform fixes improve specific cases; they are not a claim that every `/nudge` or `/move` case is solved.
- Redstone Audit is static guidance, not a circuit simulator or automatic repair tool. Findings have confidence levels and can be false positives.
- Commands/tool edits wait during the requesting player's chunked work. This is not a region lock against other players or other plugins editing the same blocks.
- Paper 1.21.11 / Java 21 is the acceptance target. WorldEdit 7.4.0 is an optional test configuration; only the configurations listed in the attached validation record are verified. FAWE, Minecraft 26.x, Folia, Spigot, Forge, and Fabric are not certified by these checks.

## Build

Run `./gradlew clean build` with Java 21 from the repository root. The result is `build/libs/bayzyl-0.2.0-alpha.2.jar`. `scripts/verify-reproducible.sh` compares two isolated builds; `scripts/write-build-receipt.sh` records the artifact hash, version, and revision.
