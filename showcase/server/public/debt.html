Read the fine print

A window into
public data.

Official data arrives on different schedules. A daily debt balance, quarterly GDP and a fiscal-year deficit describe different periods.

“Derived” means calculated from dated inputs. “Stale” means a source failed to refresh or its observation is older than this dashboard's cadence threshold. “Unavailable” means we have no valid observation. Historical series remain historical.

How to read this dashboard

All money is normalized to U.S. dollars before calculation. Annual rates are labeled and are not monthly spending. Negative surplus/deficit figures follow the source's sign convention; derived deficit per citizen uses spending minus receipts.

Observation dates for monthly, quarterly and annual data identify a period, not the date of publication. Ratio histories pair each observation with the latest input dated at or before it; they are calculated using today's revised source history, not a real-time vintage archive.

Per-person views divide by dated population observations. A national balance divided by population is context, not an individual obligation. Charts show actual returned coverage, up to six years; debt subject to limit currently covers up to one year. Lines connect observations without inventing intermediate data.

Data is cached for six hours. Manual refresh is limited to one upstream round per minute. Only the clearly labeled headline estimate ticks, using running time since refresh; pausing excludes paused time. The dated official balance, charts and register stay unchanged between source updates. This is an informational data explorer, not financial advice.
