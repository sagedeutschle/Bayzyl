Shorepact Privacy Policy

Published by Sage Deutschle · Updated November 5, 2026

This policy covers the Shorepact browser playtest and compatible crossplay clients, as well as the existing Apple game. How your game uses data depends on the table you choose.

Playtest access

The browser playtest verifies an invite pass on the server. If accepted, the server sets an expiring, HTTP-only session cookie for playtest access. Browser scripts cannot read this cookie. Clearing site data removes it. The pass admits you to the playtest, while a lobby code identifies a particular private table.

Crossplay tables

When you create a table, enter a code or request a random match, your device connects to our matchmaking service. It processes the connection origin, requested table size, seat, lobby code when applicable, and whether you are waiting, playing or disconnected. The service assigns the seats and routes game commands and board updates between the host and guests.

One player’s device hosts the rules and holds the whole game, including the shuffled deck and every hand. Each guest receives a board view containing their own hand and public information about the other seats. The relay operator can read the messages it routes, including the private hand in each guest’s board update. An encrypted connection protects these messages in transit. A player with a private table’s code can take an available seat, so share it only with the people you want to play with.

Some private tables can connect peers directly when their devices and networks allow it. Connection setup can exchange network addresses through the relay and with peers. Random matchmaking and the Discord Activity use the relay. Playtest rooms are held in service memory. Leaving a running match ends it for the table.

On your device

The browser saves your selected artwork in local storage. A browser practice game and an online game last for the current session. Clearing site data removes the browser’s saved preference. Native local tables can also store saves, settings and bot details in app storage. Use the app’s local or cloud save controls as appropriate before removing it.

Apple and Discord

Apple builds offering Game Center use Apple’s matchmaking and GameKit for those matches. Your Game Center name can be visible to other players. Optional iCloud saved games are stored in your Apple account. Older versions that offer Game Center alone cannot join a crossplay code table. See Apple’s privacy policy.

When launched within Discord, the Activity runs inside Discord’s client and network proxy. Its invitation control passes the lobby code and invitation text to Discord’s share dialog. Discord handles the account, delivery and link. Browser play outside Discord does not require a Discord login. See Discord’s privacy policy.

Website and support

Prismet’s host and network providers process connections needed to deliver the website and relay. The playtest uses addresses in memory to limit rapid requests and simultaneous connections. It removes expired one-minute rate counters on a fifteen-second sweep. Routine hosting records can include an IP address, request path and time, browser information and error status. If you email support, the message and your reply address reach the publisher. The game does not use advertising or sell personal information.

You can play against a bot instead of joining an online table, clear saved browser data, or manage Game Center and iCloud through your Apple account. Contact the publisher about a privacy question or request. Include the general platform and date, and keep passwords and active private table codes out of your message.
