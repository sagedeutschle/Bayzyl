Browser playtest and native editions · Published by Sage Deutschle

Need help or found a bug? Email sagedeutschle@pm.me.

Please include your device, browser or app version, the kind of table you chose, and what happened. Screenshots help. Please leave passwords, payment details and active private lobby codes out of reports.

Browser and crossplay tables

Open the browser playtest on the device you want to use and enter your playtest invite pass. The pass opens the playtest. A separate eight-character lobby code joins one table after admission. The browser remembers admission in an expiring cookie. When it expires, enter the pass again. The playtest includes the original game on a 19-tile island. You can practice against a bot or share a table with two to four players.

How do I play with friends?

Choose the number of players and select Create a private table. Share its eight-character lobby code. On a compatible client your friends enter the code and select Join. The game starts when every seat is filled. Each player can choose their own artwork in Settings.

How does random matchmaking work?

Choose a table size and select Find a random match. Keep the page open while players requesting the same size join. You can cancel while waiting. If nobody else is looking for that size, try a smaller table or use a code with friends.

Can I use an older Apple build or invite someone through Discord?

All players need the crossplay table menu. A build showing only Game Center uses Apple’s separate matchmaking. A friend can open the browser playtest to join your crossplay code. When playing inside the Discord Activity, its invitation control opens Discord’s share dialog. A recipient still selects Join to take a seat.

My code failed or a player disconnected.

Check that you have the code for an open private table. The host must still be waiting and a seat must be available. If someone leaves after the game starts, the online table ends. Create a new one to play again.

Where is my saved game?

Browser practice and online tables end with the session. In the native apps, use the local-game area to resume a saved table on the same device. Apple builds offering Cloud saves can restore a table you previously saved to iCloud with the same Game Center account.
