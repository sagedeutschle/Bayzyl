## summary
Command Helm keeps coding work within reach when you step away from the desk. Choose a paired computer, send a task, follow progress and answer questions as they arrive. Reports stay with the work, and persistent terminal sessions offer a place to return when a job needs closer attention.

The gallery uses the app’s built-in sample data, so you can see the real interface without exposing private computers, commands or reports. A compatible host and a configured connection are required for remote work.
