## summary
KYZER explored a Python assistant built around locally hosted models, explicit memory and a command-line/API workflow. It established an early scaffold for later local-agent work. The original service was retired in favor of Castra, and its unfinished roadmap remains historical.

## facts
- Phase: Historical prototype
- Stack: Python · FastAPI · SQLite · Ollama
- Review: Source inspected · 31 October 2026

## highlights
- The documented scaffold includes a CLI and FastAPI server.
- Uses an Ollama chat wrapper and SQLite conversation storage.
- Supports explicit fact memory.
- Tool, vector, reading-log and scheduler modules were documented as future or stubbed work.
