## title
Uncle Scam

## subtitle
A tax receipt that makes public spending personal.

## status
Live web tool

## year
2026

## role
Web interface, calculation model and source-data integration.

## summary
Uncle Scam turns a salary and ZIP code into an estimated tax receipt, with federal, state and supported local calculations. Spending breakdowns, source dates and partial-estimate labels make the result inspectable; the calculations run in the browser.

## facts
- Phase: Live web tool
- Stack: JavaScript · HTML · CSS · Public data
- Review: Source inspected · 31 October 2026

## highlights
- A browser calculation with an itemized receipt.
- Explicit partial and lower-bound labels when coverage is incomplete.
- Shows income-tax estimates alongside typical sales and property-tax estimates.
- Includes rent/own choices and exports both receipt views.
- Estimates depend on the bundled source year and geographic coverage; they are not a personal tax filing.
