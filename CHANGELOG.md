# Changelog

## 0.2.0-alpha.2 — 2026-10-04

Builder reliability pre-release. [Full update notes](docs/releases/0.2.0-alpha.2.md).

- Added atomic recovery snapshots, durable clipboards, interrupted-copy resume, and read-only Redstone Audit.
- Added checked work limits, permission/command descriptor parity, release metadata, and reproducible-build CI.
- Fixed invalid-mask widening, native edit bounds, formula validation, unsafe navigation, and selection overflow.
- Preserved partial cut/paste undo on cancellation, quit, and shutdown; prevented overlapping commands/tools for a busy player.
- Corrected clipboard rotations/mirrors, painting anchors, old detail brush codes, saved-name validation, shared kit overwrite, and autocomplete.
- Documented alpha limitations and separated runtime verification from older screenshots.
